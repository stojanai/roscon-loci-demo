Case 1 · the edit a reviewer approves

"Let's smooth the speed estimate."

The motivation: the EKF's ground-speed estimate is noisy, so pump rate jitters and the field gets streaky, uneven dose. A developer adds a median filter to clean it up — textbook signal hygiene, and pump flow is genuinely tied to speed in real spray systems.

// median filter over the last 1024 samples
static float speed_history[1024];
float sorted[1024];              // ← local
for (i=0;i<1024;i++) sorted[i]=history[i];
// insertion sort … O(n²)
for (i=1;i<1024;i++){ …swap… }
ground_speed = sorted[512];

It looks like good engineering. It compiles without a warning. In SITL the drone flies.

Two things hide in plain sight:
 · float sorted[1024] — a 4 KB array on the stack
 · an O(n²) sort — every single call

Real problemlarge local arrays overflowing a shared RTOS task stack is a documented embedded pitfall — written up by IAR, Embedded.com, and Memfault's Interrupt blog ("Measuring Stack Usage"). It's the exact failure LOCI reads from the frame.

Case 2 · a different, plausible edit

"Compensate for wind drift."

The motivation: wind blows the spray plume sideways, so chemical lands on the wrong rows — waste, and off-target damage. A developer adds a droplet-drift physics model to trim pump rate and keep dose-per-area on target. Real agronomy, not a toy.

// integrate drift over 64 droplet-size bins
for (i=0; i<64; i++){
  w  = expf(-0.5*ld*ld);
  t  = sqrtf(2*h/g) + h/(v+0.01);
  rw = wind*cosf(dir) - gs*0.01;
  drift += w*fabsf(rw*t)*(1+sinf(d));
}
pos *= 1 + drift*0.05;

Tiny stack. Compiles clean. Flies fine in SITL. A different failure class entirely — this one is a timing bomb.

64 iterations × transcendental math (sinf · cosf · expf · logf · sqrtf), buried in a new helper the sprayer calls every update.

Real problemvariable-rate & drift/lag-compensated spraying is active UAV research — e.g. the PWM "lag-compensation algorithm" work and automatic wind-drift systems. The physics is real; its per-cycle CPU cost is what nobody measures.
